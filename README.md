# VeryOwnWebOS
My very own web OS

This Web OS is a website based off of The Chosen Cheese! From Slay the Spider 2, for uneducated viewers. 

Its made in html, CSS, and JS and was made by following the Jam hackclub mission!

It includes two windows explaining the greatness of The Chosen Cheese, which are also moveable!

The website also contains a topbar which can toggle the active-ness of the Welcome window, as well as displaying the time.

Finally, there are two apps! One, called Relic Rater, leads to just a plain list of random Relics and my personal opinions on them. The second app, Cheese Idler, is sort of an idle game in which you make a certain amount of Cheese Per Second (CPS), which can be increased by purchasing the relics from the Relic Rater app.
